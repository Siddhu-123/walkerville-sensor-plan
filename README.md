# Walkerville Sensor Plan

Client demo of the Simulation 2.5 sensor placement plan for the Walkerville sewer network (Adelaide University capstone PG-S2-22 for SA Water).

Run it from this folder with any static server, then open `demo.html`:

```
python3 -m http.server 8766
```

Use the arrow keys or the on-screen buttons to move through the scenes.
